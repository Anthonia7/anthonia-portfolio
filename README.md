# Anthonia Churchill — Data Analyst Portfolio

A single-page portfolio site for Anthonia Churchill, a data analyst, showcasing her tools, technical skills, and featured analytics projects.

## Tech

Plain static HTML/CSS/JS — no build step or framework. The dashboard preview image is served through the Netlify Image CDN for optimized delivery.

## Running locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
netlify dev
```

## Structure

- `index.html` — the entire site (hero, about, tools, skills, projects, footer)
- `img/` — static image assets (e.g. the e-commerce dashboard preview)
